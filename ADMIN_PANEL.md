# Административная панель заявок

## Что доступно

- вход по паролю администратора;
- список заявок из всех форм сайта;
- изменение статуса заявки: «Новая», «В работе», «Выполнена», «Отменена»;
- фильтр заявок по статусу;
- поиск по имени, телефону, e-mail, задаче и комментарию;
- фильтр по датам;
- скачивание прикрепленных файлов;
- выгрузка текущего списка в Excel (`.xlsx`);
- постоянное хранение базы и файлов во внешнем Docker volume.

## Запуск на сервере

1. Скопировать `.env.example` в `.env`.
2. Задать длинные уникальные значения `ADMIN_PASSWORD` и `SECRET_KEY`.
3. При необходимости заполнить `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
4. Запустить проект:

```bash
docker compose up -d --build
```

5. Убедиться, что внешний прокси направляет домен на порт `8085`.
6. Открыть:

```text
https://sintegra-additive.ru/api/admin
```

Пароль — значение `ADMIN_PASSWORD` из `.env`. После первого входа заявки будут сохраняться в базе `leads.db` внутри volume `sintegra-data`, а файлы — в его каталоге `uploads`.

## Проверка

```bash
curl -I http://localhost:8085/api/health
docker compose ps
docker compose logs api --tail 100
```

Ожидаемый ответ health-проверки — HTTP 200 и JSON `{"ok":true}`.
